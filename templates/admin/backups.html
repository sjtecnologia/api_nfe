Configuração de Backup Automático

Para configurar backups automáticos via cron:

  1. Abra o crontab: crontab -e
  2. Adicione uma das linhas abaixo conforme sua necessidade:
Exemplos de Agendamento:
Frequência Comando Cron
Diário às 2h da manhã 0 2 * * * cd {{ backup_dir|replace('/backups', '') }} && ./backup_database.sh
A cada 6 horas 0 */6 * * * cd {{ backup_dir|replace('/backups', '') }} && ./backup_database.sh
A cada 12 horas 0 */12 * * * cd {{ backup_dir|replace('/backups', '') }} && ./backup_database.sh
Semanal (Domingo 3h) 0 3 * * 0 cd {{ backup_dir|replace('/backups', '') }} && ./backup_database.sh
Dica: Backups antigos são automaticamente removidos após 30 dias (configurável em config/settings.py).

Restauração de Backup

⚠️ ATENÇÃO: A restauração é uma operação destrutiva que substitui todos os dados atuais!

Para restaurar um backup via terminal:

  1. Baixe o backup desejado usando o botão de download acima
  2. Execute o script de restauração: ./restore_database.sh backups/backup_sjtnfe_YYYYMMDD_HHMMSS.sql.gz
  3. Confirme a operação digitando SIM quando solicitado
  4. Aguarde a conclusão e verifique o log gerado
Importante:
  • Faça sempre um backup atual antes de restaurar
  • Certifique-se de que nenhum usuário está usando o sistema
  • Teste a restauração em ambiente de desenvolvimento primeiro
