Como Funcionam os Webhooks
  1. Configure a URL: Seu servidor deve ter um endpoint que aceite POST requests
  2. Selecione eventos: Escolha quais eventos você quer monitorar
  3. Configure secret: Use um secret para validar a autenticidade
  4. Responda rápido: Seu endpoint deve responder em até 30 segundos com status 2xx
  5. Valide a assinatura: Verifique o header X-EmiteMax-Signature

Validação de Assinatura

Python:

import hmac
import hashlib

signature = request.headers.get(
    'X-EmiteMax-Signature'
).replace('sha256=', '')

payload = request.get_data(as_text=True)

expected = hmac.new(
    secret.encode(),
    payload.encode(),
    hashlib.sha256
).hexdigest()

is_valid = hmac.compare_digest(
    expected, signature
)
