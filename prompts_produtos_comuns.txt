# 🎯 PROMPTS ESPECÍFICOS PARA PRODUTOS COMUNS

## 📋 INSTRUÇÕES DE USO:
1. Abra seu LM Studio
2. Configure o System Prompt (veja no arquivo `exemplos_prompts_llama.txt`)
3. Copie qualquer prompt abaixo
4. Cole no chat da Llama-3.1-8B
5. Pressione Enter e veja a classificação!
