APÓS UPLOAD DOS ARQUIVOS:
=========================

1. Executar migração do banco de dados:
   python deployment/atualizar_banco_a3_windows.bat

2. Instalar nova dependência:
   pip install PyKCS11

3. Instalar drivers dos tokens:
   - SafeNet: https://support.globalsign.com/ca-certificates/local-registration-authorities-lras/safenet-drivers
   - Certisign: https://www.certisign.com.br/downloads
   - Gemalto: https://www.thalesgroup.com/en/markets/digital-identity-and-security/government/customer-services/software-downloads

4. Reiniciar serviços:
   net stop api_nfe_principal
   net start api_nfe_principal


VERIFICAÇÃO PÓS-DEPLOY:
=======================

1. Acessar: http://servidor/admin/certificados?cliente_id=1
2. Verificar se aparecem dois botões: "Certificado A1" e "Certificado A3"
3. Clicar em "Certificado A3"
4. Verificar se abre o wizard de 3 passos


NOTAS IMPORTANTES:
==================

- A migração adiciona 4 novas colunas na tabela certificados_digitais
- Certificados A1 existentes continuam funcionando normalmente
- PyKCS11 requer SWIG no Windows (incluído na maioria das instalações Python)
- Tokens devem estar conectados via USB durante o uso
- Drivers específicos do fabricante do token devem estar instalados
