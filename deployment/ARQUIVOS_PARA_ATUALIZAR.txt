SOLUÇÃO DE PROBLEMAS
============================================================================

PROBLEMA: "psql não é reconhecido como comando"
SOLUÇÃO: Ajustar caminho no atualizar_banco_windows.bat
         Trocar "C:\Program Files\PostgreSQL\16\bin\psql.exe"
         pelo caminho correto da instalação do PostgreSQL

PROBLEMA: "Erro de permissão ao executar SQL"
SOLUÇÃO: Executar cmd.exe como Administrador antes de rodar o .bat

PROBLEMA: "Campo crt já existe"
SOLUÇÃO: Normal! O script detecta e pula este passo automaticamente

PROBLEMA: "Frontend não carrega classificações"
SOLUÇÃO: 1. Verificar se API está acessível:
            http://192.168.0.52:8080/admin/api/classificacoes-ibs-cbs
         2. Abrir Console do navegador (F12) e verificar erros
         3. Verificar se dados foram inseridos no banco:
            SELECT * FROM classificacoes_ibs_cbs;

PROBLEMA: "Campos não aparecem para Lucro Real"
SOLUÇÃO: 1. Verificar campo crt em regimes_tributarios:
            SELECT id, nome, crt FROM regimes_tributarios;
         2. Regime Lucro Real deve ter crt = 3
         3. Atualizar manualmente se necessário:
            UPDATE regimes_tributarios SET crt = 3 WHERE id = 2;
            UPDATE regimes_tributarios SET crt = 3 WHERE id = 3;

PROBLEMA: "Erro 500 ao acessar emissão de NFe"
SOLUÇÃO: 1. Verificar log do Flask no servidor
         2. Verificar se models.py tem import ForeignKeyConstraint
         3. Reiniciar serviço EmiteMax

Em caso de problemas durante a atualização:

3. Anote mensagens de erro completas

   - PostgreSQL: C:\Program Files\PostgreSQL\16\data\log\
   - Flask: pasta logs/ do projeto

Para reverter a atualização (se necessário):
1. Restaurar backup do banco:
   psql -U postgres -d sjtnfe < backup_sjtnfe_AAAAMMDD_HHMM.sql
2. Restaurar arquivos do backup
3. Reiniciar serviço
