OPÇÃO A - DEPLOY AUTOMATIZADO (Recomendado):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Upload do script:

  2. Executar no servidor:
     ssh user@servidor
     sudo /tmp/deploy_api_v2.sh

  ✅ O script faz automaticamente:
     • Backup do banco e código
     • Verificação de arquivos
     • Execução da migration
     • Ajuste de permissões
     • Restart do serviço
     • Testes básicos

OPÇÃO B - DEPLOY MANUAL:
━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  BACKUP (CRÍTICO!)
      sudo -u postgres pg_dump sjtnfe > backup_$(date +%Y%m%d).sql

  2️⃣  UPLOAD DOS ARQUIVOS
      # Via SCP (copiar comandos do COMANDOS_DEPLOY_RAPIDO.md)
      scp auth/api_key_auth.py user@servidor:/var/www/api_nfe/auth/
      scp routes/*.py user@servidor:/var/www/api_nfe/routes/
      ... (ver arquivo completo)

  3️⃣  EXECUTAR MIGRATION
      cd /var/www/api_nfe
      sudo -u postgres psql sjtnfe -f database/migrations/add_api_keys.sql

  4️⃣  AJUSTAR PERMISSÕES
      sudo chown -R www-data:www-data /var/www/api_nfe
      sudo chmod -R 755 /var/www/api_nfe/templates

  5️⃣  REINICIAR SERVIÇO
      sudo systemctl restart api_nfe

  6️⃣  TESTAR
      curl http://localhost:8080/api/v2/nfes
      # Deve retornar: {"error": "API Key não fornecida"}
