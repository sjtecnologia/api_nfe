PARTE 7: SOLUÇÃO DE PROBLEMAS
============================================================================

PROBLEMA 1: Serviço não inicia
SINTOMA: net start retorna erro
SOLUÇÃO:
1. Verificar log: notepad C:\inetpub\wwwroot\api_nfe\logs\app.log
2. Erro comum: "ImportError: cannot import name ForeignKeyConstraint"
   → Verificar se models.py tem na linha 1:
     from sqlalchemy import [...], ForeignKeyConstraint
3. Erro comum: "ModuleNotFoundError: No module named 'services.ibs_cbs_service'"
   → Verificar se arquivo existe: services\ibs_cbs_service.py
   → Verificar se pasta services tem arquivo __init__.py

PROBLEMA 2: API retorna 404
SINTOMA: /admin/api/classificacoes-ibs-cbs retorna "Not Found"
SOLUÇÃO:
1. Verificar se routes/admin_routes.py foi substituído
2. Verificar fim do arquivo admin_routes.py:
   grep -A 5 "classificacoes-ibs-cbs" routes/admin_routes.py
3. Se não encontrar, copiar novamente o arquivo

PROBLEMA 3: Campos não aparecem
SINTOMA: Cliente Lucro Real não mostra seções IBS/CBS
SOLUÇÃO:
1. Abrir Console (F12) → aba Network
2. Recarregar página
3. Procurar chamada: regime-tributario/<id>
4. Ver resposta - deve ser: {"success": true, "crt": 3, "requer_ibs_cbs": true}
5. Se retornar crt=1, atualizar banco:
   UPDATE regimes_tributarios SET crt = 3 WHERE id IN (2,3);

PROBLEMA 4: Select vazio
SINTOMA: Select "Classificação IBS/CBS" não tem opções
SOLUÇÃO:
1. Testar API: http://192.168.0.52:8080/admin/api/classificacoes-ibs-cbs
2. Se retornar vazio, executar:
   psql -U postgres -d sjtnfe
   SELECT * FROM classificacoes_ibs_cbs;
3. Se tabela vazia, inserir manualmente:
   INSERT INTO classificacoes_ibs_cbs (codigo, descricao, aliquota_ibs_uf, aliquota_ibs_mun, aliquota_cbs, ativo)
   VALUES 
   ('000001', 'Medicamentos e produtos de higiene pessoal', 0.10, 0.00, 0.90, true),
   ('000002', 'Produtos alimentícios básicos', 0.50, 0.00, 1.50, true),
   ('000003', 'Outros produtos', 1.00, 0.00, 2.50, true);

PROBLEMA 5: Erro JavaScript
SINTOMA: Console mostra "verificarRegimeTributario is not defined"
SOLUÇÃO:
1. Verificar se templates/admin/nfes/emitir.html foi substituído
2. Abrir arquivo e procurar: "async function verificarRegimeTributario"
3. Deve estar entre as tags <script>...</script>
4. Se não encontrar, copiar novamente o arquivo

PROBLEMA 6: Backup do banco não funciona
SINTOMA: atualizar_banco_windows.bat diz "pg_dump não reconhecido"
SOLUÇÃO:
1. Editar arquivo: atualizar_banco_windows.bat
2. Procurar linha: "C:\Program Files\PostgreSQL\16\bin\pg_dump.exe"
3. Ajustar para seu caminho real do PostgreSQL
4. Exemplos:
   - PostgreSQL 15: C:\Program Files\PostgreSQL\15\bin\pg_dump.exe
   - PostgreSQL 14: C:\Program Files\PostgreSQL\14\bin\pg_dump.exe
